# Sales Dashboard – Power BI Project  

## 📌 Introduction  
This project showcases a **Sales Dashboard** created using **Microsoft Power BI**.  
All steps including **data transformation, modeling, calculations, and visualization** were performed within Power BI.  



## 🛠 Tools & Technologies  
- **Power BI** → Data transformation (Power Query), modeling, and dashboard creation  


## 📊 Dashboard Features  
- Revenue, orders, and profit KPIs  
- Monthly sales and profit trends  
- Category-wise sales and profit performance  
- Store-level analysis  
- Top products by sales
